How this gets made

AI helps me make this. It does not make it.

That's the test I hold my own work to, so here's how the work here actually gets made.

Every essay here starts with me, written from things I actually did or got wrong. An issue of The Animation Frontier can't go out while my section is still an empty placeholder.

Around that, AI does real work. It researches, it checks the links, it drafts the sections that are summaries rather than opinions, it catches me repeating myself, and it takes on a lot of the admin. I read all of it and I cut a lot of it.

The pictures follow the same rule. The diagrams and tip graphics are built from real text rather than painted by an image model, so the words in them are the words I wrote. I put a “Created with AI” stamp on them either way, so you never have to guess which is which.

I'm not going to publish AI-made animation under my name. I run tests in private so I can talk about this from experience instead of guessing, and that work stays there.

If something I make ever stops passing that test, tell me.
